## 確定しているプロダクト方針

- ふたりの2アカウントで同じ結婚式データを共有する。
- タスク・資料・ゲスト・世帯・お金・検討/決定を1つのWedding配下で管理する。
- Excelは初回移行専用。通常運用の入口にはしない。
- 通常運用は、メール本文・文章・写真・PDF・カタログなどを登録し、AIが登録候補を作り、確認後に反映する流れにする。
- 原文・画像・PDFは保存して残す。AI抽出結果には根拠を紐付ける。
- AIは出欠、世帯紐付け、金額、支払状態などを無確認で上書きしない。候補として提示し、利用者が承認する。
- 世帯コードは画面の主要情報にしない。DB上の照合・重複防止用に内部保持する。
- 世帯名は表示し、人数・出欠・ご祝儀・引き出物を中心に見せる。
- タスク一覧は一覧を主役にし、絞り込みはモーダルで開く。行はコンパクトにする。
- ブラックテーマは設定へ置く。サイドバーは折りたたみ可能。

## ガント表示の並び順（2026-09-11実装済み）

ガントはデフォルトで今日を含む週/月を表示し、開いているタスクを次の順に並べる。

1. 期限超過（期限の古い順）
2. 今日が開始日〜期限日の期間内に含まれるもの（進行中、未着手の順。期限の近い順）
3. 7日以内に期限が来るもの（期限の近い順）
4. それ以降の期限があるもの（期限の近い順）
5. 日付なしはガント本体から分離して「日付なし」に表示

同じ条件では、進行中 → 未着手、期限日時、開始日、登録順の順で安定させる。手動の優先度項目は追加せず、期限と進捗から自動順位付けする。前後の期間へ移動した場合は、その表示範囲内で時系列が自然になるように扱う。

月表示は対象月の月初を含む週の開始日から、月末を含む週の終了日まで表示する。月またぎのタスクは同じバーで連続表示し、月初に境界線と月ラベルを表示する。前後月への移動は月初を基準に行う。

ガントのバーはドラッグで日程を移動でき、クリックで詳細編集へ移る。現在の月/週を中央に表示し、左右矢印で前後へ移動できる。「今日」で現在日を含む範囲へ戻せる。

## 最近の変更画面の改善（2026-09-11実装済み）

現在のダッシュボードでは、同じ時刻に発生したゲスト変更などを1グループにまとめている。64件の個別変更をそのまま縦に表示すると、変更履歴のカードが長くなり、日時や変更内容も追いにくい。

次の表示に変更した。

- 新しい変更を上から並べ、`created_at DESC, id DESC` で時系列を固定する。
- グループの見出しは「ゲストの変更 64件」のように概要だけにする。
- `2026/09/10 00:20` の日時を常に表示する。
- 個別変更は折りたたみ式にし、開いた内容は内部スクロールにする。
- 履歴全体にも最大高さを設定し、ダッシュボード全体が長くなりすぎないようにする。
- PCでは日時を右側、スマホでは変更内容の上に置く1列レイアウトにする。
- ゲスト、タスク、資料、お金、検討・決定をアイコンで区別する。
- 64件の変更があってもページ全体に長い箇条書きを出さない。

履歴の回帰テストでは、最新順、日時表示、グループ詳細の折りたたみ、内部スクロール用の意味的な領域、スマホ幅での1列構成を確認している。
