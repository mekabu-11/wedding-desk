# タスクの追加とExcel移行データの取り込み

初回の全体移行は「やること → Excelをまとめて移行」を使います。2つのxlsxを同時に選択すると、対象シートを統合した行別プレビューが作られます。確認後に世帯・ゲスト・引出物・収支・タスク・BGMを一括反映します。数式は実行せず、式キャッシュや実績額は要確認として保持します。旧JSON取り込みは既存データの追加用途として利用できます。

2026-09-06実装。Rails/PostgreSQL/Dockerを継続する。

## 利用方法

1. ログインし、未設定の場合は結婚式情報を登録する。
2. 「やること → データを取り込む」を開く。
3. ローカルの `artifacts/excel-import-20260906/import_candidates.json` を選択する。
4. 45件のタイトル・開始日・期限・状態・メモを確認し、元の担当名を自分・パートナー・二人・未設定へ割り当てる。
5. 確認チェックを入れて登録する。完了9件は一覧の「完了」フィルタで確認できる。

新しいタスクは「やること → タスクを追加」で作成できる。タスクを開けば、開始日・期限・担当・状態・カテゴリ・詳細を編集できる。インポートしたタスクには元ファイル名・シート・行番号・元の担当とカテゴリを残す。

今週表示は、開始日と期限の期間が今週（月〜日）に重なるものを対象にする。開始日がなければ今週が期限のものを表示する。期限がないタスクは期間「すべて」で確認する。期限超過は別の期間フィルタを使う。期限日時は日本時間で判定する。

## 取り込み仕様と制限

- JSONの対応は形式1（groups.tasks）、2MB以下・1〜500件です。xlsx全体移行の上限は各25MB、展開後100MB、合計10,000行です。
- 元Excel用の変換スクリプトは `artifacts/excel-import-20260906/prepare_wedding_import.py`。今回の2ブックに特化した解析用で、汎用Excel変換機能ではない。準備済みJSONはそのまま使えるので利用時にPythonは不要。
- 他のgroups（ゲスト・収支・BGM等）は読まず、DBにも保存しない。
- 日付、文字数、状態、出典を検証し、不正な行があるファイルは確認画面へ進めない。数式は実行しない。
- 日付はYYYY-MM-DD、またはExcel抽出時のYYYY-MM-DDT00:00:00を受理する。時間のある値を日付へ切り捨てない。
- カテゴリは既存の分類へ対応付ける。一意に対応しない「衣装」等は「その他」とし、元のカテゴリを出典に保持する。必要に応じて取り込み後に編集する。
- ファイルハッシュ・シート・行番号から出典キーを作成。同じ結婚式で同じ出典を取り込んでも既存タスクを更新しない。全行の追加と結果記録はトランザクション内で行う。
- 元xlsxを編集しハッシュが変わったファイルの意味的な重複検出・差分更新は未対応。再取込時は元ファイルとの差異を確認する。
- プレビューの元行とタスクの本文・出典情報はActive Record Encryptionで暗号化する。ユーザー入力のwedding_idやoriginでは所有者・出典区分を変更できない。
- AI由来タスクは承認時に候補と結び付く。資料削除時は候補との参照を外してタスクと暗号化した出典概要を保持する。手動/Excelタスクも資料削除の対象にならない。

## Dockerでの更新

新しい環境は従来どおり `bin/setup`。既存環境は次を順番に実行する。

```sh
docker compose build
docker compose run --rm web bin/rails db:prepare
docker compose up -d web worker
```

新しい環境変数は不要。既存の.envとAR_ENCRYPTIONの3変数を保持する。稼働中のdevelopment環境にはマイグレーションを適用済み。公開環境への配置は `docs/deployment.md` に従い、migration後に同じ版のweb/workerへ更新する。今回の変更を外部サーバーへは配置していない。

## 検証

Docker内のテストで手動追加、編集、権限拒否、アップロード、確認必須、暗号化、再送、手修正維持、全件ロールバック、日付境界を検証した。実ファイルの45行もDBへ保存せずに取り込みサービスで検証済み。

ブラウザでは専用の一時アカウントと架空データでログイン、390px幅のフォーム入力・保存、1280px幅のプレビュー・登録を確認。両サイズで横はみ出しなし。確認用アカウントとデータは削除済み。iPhone/Android実機での確認は未実施。

利用者の45件はまだ本登録していない。画面で担当の対応を選んで確定すると登録される。ゲスト・世帯・収支・BGM画面は後続段階。
