届いたメールやLINE、打ち合わせメモを残して、次にやることを一緒に管理するための使い方ガイドです。

このページの画面例は、個人情報を含まないサンプルデータで作成しています。実際の画面では、登録した結婚式名・資料・タスクが表示されます。

1ログインする

管理者から渡されたメールアドレスとパスワードでログインします。登録・招待機能はなく、ふたりだけで使う前提です。

画面例：メールアドレスとパスワードを入力してログイン
パスワードを忘れた場合
現在のMVPにはパスワード再発行画面がありません。管理者が環境変数 APP_PASSWORD を更新して再起動します。

2ダッシュボードで今日の状況を見る

ログイン後の「ダッシュボード」には、確認待ちの候補、これからやること、完了したこと、最近の資料がまとまります。

画面例：期限の近いタスクと最近登録した資料をひとつの画面で確認

確認待ちの候補

登録した連絡から見つかった、まだタスク化していない候補です。原文と照らし合わせて判断します。

これからやること

期限・担当・状態をもとに、次に進めるタスクが表示されます。タスクを開いて状態を更新できます。

トップ写真を設定する
「結婚式の設定」からふたりの写真を登録すると、ダッシュボードの上部に表示できます。JPG・PNG・WebP・HEIC、10MBまで対応しています。

3連絡や資料をそのまま登録する

「資料と連絡」から「＋ 連絡を登録」を開き、文章を貼り付けるか写真・PDFを添付します。情報元は入力形式から自動で分類され、原文と添付は保存されます。

  1. メールやLINEから必要な文章をコピーする、または資料を撮影する
  2. 文章欄に貼り付けるか、写真・PDFを添付する
  3. 保存して、必要ならAI整理を開始する
現在のAI機能
資料は保存できますが、外部AIへの送信は停止中です。AI整理を実行しても外部へ本文や添付を送らず、安全に失敗します。

4画像・PDFを添付する

本文がない資料も保存できます。スマホのカメラで撮影するか、端末から画像・PDFを複数選びます。

  1. 「資料と連絡」から「＋ 連絡を登録」を開く
  2. 本文を貼り付けるか、画像・PDFを選ぶ
  3. 保存後、資料詳細の添付リンクから内容を確認する
添付の上限
JPEG・PNG・WebP・HEIC・HEIF・PDFを1資料10個まで。1ファイル20MB、合計50MB、画像40MP、PDF20ページまでです。SVGと暗号化PDFは保存できません。
ファイルの扱い
添付はログイン中の同じWeddingの利用者だけが開けます。CSVエクスポートには添付原本を含めません。

5候補を確認してタスクにする

資料の詳細画面では、左に原文、右に整理された候補が表示されます。期限・担当・内容が原文と合っているものだけ確認して追加します。

画面例：原文を見ながら、タスク候補の内容・期限・担当を確認

確認して追加

チェックした候補だけが「やること」に追加されます。確認前の候補は残るため、あとで戻れます。

タスクの編集

「やること」でタスクを開くと、タイトル・担当・期限・メモ・状態を変更できます。

6Excelからタスクを移行する

「結婚式の設定 → 初回データ移行 → Excelをまとめて移行」から2つのxlsxを選び、統合プレビューで警告と担当A/Bを確認してから一括登録します。数式は実行せず、実績額や日付不明の金額は要確認で残ります。旧JSONのタスク取り込みも利用できます。

BGMシートの「〃」「同上」は直前のシーンにまとめ、内容のない行は候補として登録しません。

画面例：import_candidates.jsonを選び、内容を確認してから登録
  1. 「やること」→「データを取り込む」を開く
  2. import_candidates.json を選び、「内容を確認する」を押す
  3. 元の担当名を「本人A」「本人B」「ふたり」に割り当てる
  4. タスク・期限・状態を確認し、「確認したタスクを登録する」を押す
同じタスクを再度取り込んだ場合
出典キーが同じタスクは重複登録されません。既存タスクの内容も上書きしません。

7検討・決定を進める

「検討・決定」から演出やBGMなどの項目を追加し、候補を複数登録します。採用時は費用の扱いを必ず選び、登録済みの金額への紐付けや新しい支出を同時に保存できます。

BGM

BGMカテゴリでは候補ごとに希望曲A/B、決定曲、アーティスト、開始秒、シーン、元表記を登録できます。

関連付け

項目詳細から費用とタスクを追加・解除できます。リンクを解除しても費用項目や入出金履歴は削除されません。

採用の変更
採用候補を変えても以前の費用項目や入出金履歴は残ります。収支は同じ費用項目を一度だけ集計します。

8準備全体を管理する

ゲスト、世帯、席次、引き出物、収支、決定事項を同じWedding内で関連付けて管理します。

タスク

状態・担当・カテゴリ・期間・文字で絞り込み、一覧または週／月のガントで確認できます。選択中のページ、または絞り込み結果を一括変更できます。

ゲストと世帯

個人を世帯にまとめ、出欠、席次、役割、ご祝儀見込、世帯ごとの引き出物を管理します。

お金

収入と支出を概算／確定で登録し、支払・受取・返金の履歴から残額を確認します。ゲスト数などに連動する概算にも対応します。

検討・決定

演出、衣装、料理、写真、BGMなどの候補と採用結果を残し、関連タスクと費用を結びます。

バックアップ
「結婚式の設定」から、業務データをUTF-8 BOM付きCSVのZIPで保存できます。添付原本は含まれません。

9毎日の使い方

新しい連絡が来たら資料として残し、候補を確認したらタスクにします。ふたりで同じ画面を見ることで、返信漏れや期限の見落としを減らせます。

連絡が来た日

  • 本文を「資料と連絡」に登録
  • 期限や担当の候補を確認
  • 必要なものだけタスクに追加

週に一度

  • 期限超過のタスクを確認
  • 担当と期限を見直す
  • 終わったタスクを完了にする
スマホでも使えます
公開後のURLをスマホのブラウザで開けば、PCと同じWeddingデータを確認・更新できます。ガント表示だけは横スクロールで操作します。
